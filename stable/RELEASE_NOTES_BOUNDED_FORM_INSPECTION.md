# Cypher 10.7.0 — Bounded Public Form Inspection

`Web: forms PUBLIC-HTTPS-URL` inspects public HTML form structure without submitting it.
The result includes bounded same-host form destinations, declared GET/POST methods and
named non-sensitive field types. The desktop system rail provides an Inspect Forms starter.

This is preparation for a future reviewed form-action capability, not form automation.
Cypher still cannot type into or submit a website through this route. The 10.6.0 release
remains the rollback copy.
