# Cypher Core Preview 10.2.0 - Bounded Office Documents

Extract the complete ZIP into a new folder and run INSTALL_CYPHER_OFFICE_DOCUMENTS.cmd normally.
Keep 10.1.1 for rollback.

Ctrl+Alt+Space opens the new opaque monochrome command center. It keeps all existing controls,
keyboard behavior, approval cards, Stop/recovery access and local/private status while introducing
mode and system rails, a responsive central workspace, grid texture, scalable title-bar icons, an
original SHA-256-verified signal-core hero image and semantic state colors.

Open Brave then visit chess.com

Search scans a bounded plain-text approved-folder scope without a model or persistent index.
Explicit document routes accept UTF-8 files up to 1 MiB, PDFs up to 8 MiB / 100 pages, or
DOCX/PPTX/XLSX files up to 8 MiB. Compare uses two to four mixed supported files and requires a
non-empty draft to cite every source. Separate pinned parser children receive PDF or Office bytes
without paths, model, network or action context. Model evidence stays capped at 4,096 text bytes.
Exact line/page/paragraph/slide/sheet-row evidence is shown; generated entailment is not proven.

The HTTPS-open form is local and deterministic. It accepts one public HTTPS domain/URL, resolves
only a human-registered app, requires one native approval, and never reads the page or address bar.
It is not interactive browser automation or a general web-search agent.

Follow [Office Documents validation](VALIDATION_OFFICE_DOCUMENTS.md) and
[Office Documents setup](OFFICE_DOCUMENTS_SETUP.md) for the focused handoff. Existing HTTPS-open/PDF,
file, research and runtime behavior remains.
