## Scope

First research slice of the adopted Bundle B roadmap: explicit public HTTPS pages, local synthesis,
source references and matched supporting passages. **Automatic source search is deferred.** No
paid search provider, API key, model download or browser access workaround is added.

The user accepted Core Preview 8.5.3's focused Calculator minimize/restore behavior. That implementation
and prior approval boundaries remain. The artificial arming pause stays absent, as requested.
Broader in-flight native interruption and crash/no-replay acceptance were not established by that test.

## Changed in 9.0.6

- Set the complete `JOBOBJECT_BASIC_UI_RESTRICTIONS` mask before worker start: foreign USER handles
  and hooks, clipboard read/write, system parameters, display settings, global atoms, desktop
  creation/switching and Windows exit calls are blocked.
- Query the job immediately and require the returned mask to match exactly. Set/query failure or a
  weakened mask returns `WORKER_UI_ISOLATION_UNAVAILABLE`; no request reaches the worker.
- Exercise the same setup during the installer's offline owned-worker self-test. No website or
  Ollama request is made by that check.
- Retain the same-user token and deterministic network policy. This is desktop-surface hardening,
  not AppContainer/filesystem/registry/network sandboxing.
- Add no approval, countdown, delay, Stop stage, provider, search call, model call or action authority.

## Retained from 9.0.5

- After resolving and revalidating a named definition's selected passages, require explicit
  conditional wording when a selected passage describes a distinct case.
- Reject unsupported scope intensifiers and substantive words of seven or more characters that are
  absent from the question and selected evidence, except a small fixed neutral comparison vocabulary.
- Return `CLAIM_SCOPE_UNSUPPORTED` with source metadata and zero findings instead of displaying any
  rejected draft claim. No automatic retry, repair generation, or partial claim salvage is added.
- Tell the same single local-model call to use direct plus general-return evidence for general claims,
  retain conditions for case evidence, and reuse source vocabulary. Structured sampling temperature
  is now zero.
- Add six regressions for rejected overgeneralization and mechanisms, accepted scoped/general claims,
  non-definition prose, and the complete metadata-only fail-closed path.

## Retained research implementation

- A native `Research:` input route, before chat and Windows workflow routing, takes one to five URLs.
- A fixed, hashed Python worker reads permitted public HTML/plain-text pages, with checked DNS/TLS,
  robots policy, bounded redirects/content/time and no browser login or execution of page code.
- The existing configured fast model handles Auto/Fast; Deep is explicit. Only an installed local
  Ollama GGUF model is used. Research receives no action tools, prior chat or approval authority.
- The model selects passage IDs from a catalog generated by the reader. The worker resolves exact
  source slices and applies the original source-ID/quotation checks. Unknown IDs, duplicate references,
  old quote fields and malformed drafts are rejected. URLs and metadata still come from the reader.
- Owned process lifetime, bounded protocol, Stop and confirmed-exit gating are added. A Stop during
  startup cannot later start the worker; active streams are not disposed before the runner finishes.
- The installer checks the pinned worker, compiles the new host, tests protocol parsing and launches
  a real worker with a rejected local URL before replacing the installed host. It also checks
  rejection of startup after Stop. No external request occurs in this offline installation check.
- The welcome/capability text states the source-URL requirement and lack of automatic search.

No new registered app actions, file permissions, durable memory, voice, vision or schedules are added.
The worker remains under the current user's token and is **not an AppContainer security sandbox**.

## Installation and rollback

Use [RESEARCH_PREVIEW_SETUP.md](RESEARCH_PREVIEW_SETUP.md) and
`INSTALL_CYPHER_RESEARCH_PREVIEW.cmd` in a fresh extracted folder, normally rather than elevated.
Keep the accepted **9.0.5** package for reinstall rollback and **v0.8.9.3 / Core Preview 8.5.3** as
the earlier workflow baseline. No historical acceptance marathon or artificial Stop countdown is
required; the installer's offline worker-start check is sufficient for this hardening-only release.

See [SECURITY_READONLY_RESEARCH.md](SECURITY_READONLY_RESEARCH.md) for the precise limits and trust
assumptions. General search and AppContainer/filesystem/network isolation remain future work, not
completed capabilities of this preview.
